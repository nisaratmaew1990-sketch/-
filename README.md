# 🐉 เกมการศึกษาออนไลน์ “ผจญภัยพิชิตดินแดนคำควบกล้ำ” 🌟
### สำหรับนักเรียนชั้นประถมศึกษาปีที่ 2 (กลุ่มสาระการเรียนรู้ภาษาไทย)

เกมผจญภัยการศึกษา 2D สไตล์การ์ตูนสดใส ออกแบบเฉพาะสำหรับเด็กนักเรียนชั้น ป.2 เพื่อเรียนรู้และทบทวนความรู้เรื่อง **คำควบกล้ำแท้** ผ่านการผจญภัย 5 ด่านสุดตื่นเต้น พร้อมระบบเกียรติบัตรดิจิทัล ระบบบันทึกคะแนนเรียลไทม์ลง Google Sheets และระบบรายงานผลสรุปสำหรับคุณครู (Teacher Dashboard)

## 🎮 จุดเด่นและฟังก์ชันของเกม

1. **เลือกตัวละครและกรอกข้อมูลผู้กล้าตัวน้อย**:
   - น้องกล้าหาญ (อัศวินน้อยพิทักษ์คำไทย 🛡️)
   - น้องแก้วใส (จอมเวทน้อยแห่งป่ามนตรา 🧙‍♀️)
   - น้องต้นน้ำ (นักสำรวจดินแดนมหัศจรรย์ 🧭)
   - น้องฟ้าใส (เอลฟ์ผู้พิทักษ์ธรรมชาติ 🧝‍♀️)
   - กรอกชื่อ-นามสกุล, ชั้นเรียน (เช่น ป.2/1), เลขที่ เพื่อออกเกียรติบัตรและบันทึกคะแนน

2. **ผจญภัย 5 ด่านมหัศจรรย์ (10 ข้อ ด่านละ 2 ข้อ)**:
   - 🌲 **ด่านที่ 1 : ป่าคำควบกล้ำ** (ข้อ 1-2)
   - 💎 **ด่านที่ 2 : ถ้ำปริศนา** (ข้อ 3-4)
   - 🌊 **ด่านที่ 3 : แม่น้ำมหัศจรรย์** (ข้อ 5-6)
   - 🏰 **ด่านที่ 4 : ปราสาทคำศัพท์** (ข้อ 7-8)
   - 🐉 **ด่านที่ 5 : ด่านพิชิตมังกร** (ข้อ 9-10)

3. **ระบบคำถามและการเสริมแรงทางบวก (Positive Reinforcement)**:
   - ข้อสอบ 3 ตัวเลือก (ก, ข, ค) ตัวหนังสือใหญ่ อ่านง่าย ปุ่มสัมผัส 3D กดสนุก
   - **ตอบถูก**: +10 คะแนน, เสียงปรบมือสังเคราะห์, เสียงดนตรีฉลอง, เอฟเฟกต์ดาวและ Confetti กระจาย, ตัวละครกระโดดดีใจ
   - **ตอบผิด**: เสียงโทนอบอุ่นให้กำลังใจ พร้อมแสดงเฉลยและคำอธิบายอย่างละเอียดแบบเข้าใจง่ายสำหรับเด็ก ป.2
   - คะแนนเต็ม 100 คะแนน | **เกณฑ์ผ่านการประเมิน 70 คะแนนขึ้นไป**

4. **📜 เกียรติบัตรดิจิทัลความละเอียดสูง (Digital Certificate)**:
   - เรนเดอร์ด้วย HTML5 Canvas คมชัด สวยงามระดับงานพิมพ์
   - ระบุชื่อนักเรียน, ชั้น, เลขที่, คะแนนที่ได้, ระดับเหรียญรางวัล (เหรียญทอง 100 / เหรียญเงิน 80-90 / เหรียญทองแดง 70), วันที่ พ.ศ. และตราสัญลักษณ์
   - ปุ่ม **“📥 ดาวน์โหลดเกียรติบัตร (PNG)”** บันทึกเป็นรูปภาพลงเครื่องทันที
   - ปุ่ม **“🖨️ พิมพ์เกียรติบัตร”** สั่งพิมพ์ออกกระดาษขนาด A4 แนวนอนได้ทันที

5. **🔊 ระบบเสียงสังเคราะห์ Web Audio API (ไม่ต้องพึ่งพาเน็ต)**:
   - ดนตรีประกอบพื้นหลัง (BGM) ทำนองน่ารักสดใส
   - เสียงเอฟเฟกต์คลิก, เสียงดาวรางวัล, เสียงปรบมือ, เสียงชัยชนะ
   - ปุ่มเปิด/ปิดเสียง (Mute Toggle) บันทึกสถานะอัตโนมัติ

6. **👨‍🏫 ระบบคุณครู (Teacher Dashboard)**:
   - ป้องกันด้วยรหัสผ่าน (ค่าเริ่มต้น: `1234`)
   - สรุปสถิติผู้เล่นทั้งหมด, คะแนนเฉลี่ย, อัตราการผ่านเกณฑ์, จำนวนคนที่ได้เต็ม 100
   - ตารางอันดับคะแนน (Leaderboard) พร้อมเหรียญ 🥇 🥈 🥉
   - ตัวกรองแยกตามห้องเรียน (ป.2/1, ป.2/2 ฯลฯ) และช่องค้นหาชื่อนักเรียน
   - ปุ่มส่งออกข้อมูลเป็นไฟล์ Excel / CSV รองรับภาษาไทย (UTF-8 BOM)

### ขั้นตอนที่ 4 : Deploy เป็น Web App
1. กดปุ่มสีน้ำเงินมุมขวาบน **ทำให้ใช้งานได้ (Deploy)** ➔ เลือก **การทำให้ใช้งานได้ใหม่ (New deployment)**
2. คลิกรูปเฟือง ⚙️ ข้าง "เลือกประเภท" ➔ เลือก **เว็บแอป (Web app)**

4. กด **ทำให้ใช้งานได้ (Deploy)**
5. คัดลอก **URL เว็บแอป (Web App URL)** ที่ลงท้ายด้วย `/exec` มาเก็บไว้

## 🚀 ขั้นตอนการอัปโหลดขึ้น GitHub & เปิดใช้งาน GitHub Pages

### กรณีใช้ Git Command Line:
เปิด Terminal หรือ Command Prompt ในโฟลเดอร์นี้ แล้วรันคำสั่ง:

```bash
# 1. กำหนดค่าเริ่มต้น Git
git init
git branch -M main

# 2. เพิ่มไฟล์ทั้งหมดเข้าสู่ Git
git add .
git commit -m "feat: Initial release of Thai Consonant Cluster Adventure Game"

# 3. เชื่อมต่อกับ GitHub Repository ของคุณ (เปลี่ยน YOUR_USERNAME และ REPO_NAME)
git remote add origin https://github.com/YOUR_USERNAME/REPO_NAME.git

# 4. Push โค้ดขึ้นสู่ GitHub
git push -u origin main
```

### การเปิดใช้งาน GitHub Pages:
1. ไปที่หน้า Repository ของท่านบน GitHub
2. ไปที่แถบ **Settings** ➔ เมนูด้านซ้ายเลือก **Pages**
3. ภายใต้หัวข้อ **Build and deployment** ➔ **Source** ให้เลือกเป็น **GitHub Actions**
4. ระบบจะรันไฟล์ `.github/workflows/deploy.yml` อัตโนมัติ เมื่อเสร็จสมบูรณ์จะได้ลิงก์เว็บไซต์ เช่น:
   `https://YOUR_USERNAME.github.io/REPO_NAME/`

### การตั้งค่า GitHub Secrets (เพื่อความปลอดภัย ไม่เปิดเผย URL ในโค้ดสาธารณะ):
1. ในหน้า GitHub Repo ไปที่ **Settings** ➔ **Secrets and variables** ➔ **Actions**
2. กดปุ่ม **New repository secret**
3. ใส่ Name: `GAS_WEB_APP_URL`
4. ใส่ Value: *วาง URL ของ Google Apps Script Web App ที่ได้จากขั้นตอน Deploy*
5. กด **Add secret** (ระบบ GitHub Actions จะนำ URL ไปตั้งค่าให้อัตโนมัติขณะ Deploy)
